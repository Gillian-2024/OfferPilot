# 法律文档（隐私政策 / 用户协议）

## 内容源（唯一事实源）

前端站内页 `/privacy` 与 `/terms` 直接渲染以下两份 Markdown，**发布时只需改这两份文件**：

- `client/src/pages/legal/privacy-policy.md` → 路由 `/privacy`
- `client/src/pages/legal/user-agreement.md` → 路由 `/terms`

页面组件：`client/src/pages/LegalPage.tsx`（`@ant-design/x-markdown` 渲染）。
入口链接：`client/src/components/Layout/index.tsx` 页脚（"隐私政策 · 用户协议"）。

## 发布前待填占位符（两份文档内的 `【】`，勿虚构）

| 占位符 | 出现位置 | 说明 |
|---|---|---|
| 【运营主体名称】 | 隐私政策 §引言/§八；用户协议 §引言/§十 | 个人或企业全称 |
| 【联系邮箱】 | 隐私政策 §八；用户协议 §二/§十 | 客服 / 隐私联系邮箱 |
| 【联系电话】 | 隐私政策 §八 | 可选 |
| 【ICP 备案号】 | 隐私政策 §八 | 备案完成后回填 |
| 【注销入口 / 联系客服】 | 隐私政策 §五 | 确认产品内有无自助注销，无则删"注销入口 /" |
| 【我们位于中国大陆境内的服务器】 | 隐私政策 §4.1 | 若服务器在境外需改写并补充数据出境说明 |
| 【15 个工作日】 | 隐私政策 §五 | 承诺的答复时限，可调整 |
| 【我们所在地】 | 用户协议 §九 | 用于确定管辖法院（通常为运营主体住所地） |
| `____年__月__日` | 两份文档头部 | 更新 / 生效日期 |

## 后续注意事项

- **接入微信 / 支付宝支付后**：实名会强制收集手机号、实名信息等，需同步扩写隐私政策 §一"收集哪些信息"。
- **BYOK 数据出境**：隐私政策 §3.2 已覆盖"自带密钥"场景（用户自填海外模型密钥即构成个人信息跨境提供），备案 / 商店审核可能被问到，此处已留底。
- **ICP 备案**：站内可访问的隐私政策页是备案常规要求，`/privacy` `/terms` 已就位。
